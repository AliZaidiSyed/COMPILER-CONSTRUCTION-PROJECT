# Compiler Construction Project

A Python-based LL(1) Parser with a graphical user interface built using Tkinter.

### Features
- FIRST and FOLLOW set calculation
- LL(1) parsing table generation
- Input string validation
- Derivation steps and parse tree visualization
- Grammar validation and error detection

### Technologies
Python, Tkinter

### How to Run
```bash
python COMPILER-PROJECT.py
```
